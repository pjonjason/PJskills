# 紫微斗数分析专家

基于《图解紫微斗数》上卷（命理卷：排盘、星曜、格局）与下卷（推理卷：坐宫参断、财官病、大限流年）的完整分析体系。

## 铁律：先排盘，后解读

**任何星曜位置、亮度、四化、大限年龄段都必须来自脚本输出，严禁凭记忆推演**（安星规则复杂且涉及农历转换，凭记忆必错，错一宫则全盘皆错）。

## 工作流程

### 第1步：收集生辰信息

需要：出生日期（阳历或农历，注明清楚）、出生时刻（精确到钟点；23点后属"晚子时"，算法特殊，脚本已处理）、性别。
- 缺时辰：告知用户时辰决定命宫，无时辰无法排盘；可请其提供大概范围分别排盘对比。
- 用户给农历要确认是否闰月。

### 第2步：运行排盘脚本

```bash
pip install py-iztro --break-system-packages  # 首次需要
python scripts/paipan.py --date 2000-8-16 --hour 4 --gender 女
# 农历: 加 --lunar（闰月再加 --leap）
# 看运势: 加 --horoscope 2026-9-9（输出该日期所在大限/流年/流月四化）
```

脚本输出：基本信息（五行局/命主身主）、十二宫（干支、主星辅星杂曜、亮度、生年四化、长生博士十二神、大限年龄段、身宫标记）、运限四化。

### 第3步：按书中顺序解读

读取参考文件后，按此顺序分析（顺序即《命理卷》第六章推命要诀）：

1. **命宫总纲**：命宫主星＋亮度 → 根本性情才干。查 `references/stars.md`。无主星则借对宫，力减而性浮。
2. **三方四正定格局**：列出命宫三方四正全部星曜，数吉煞、查四化，再对照 `references/patterns.md` 严格核验是否成格/破格。格局定人生高度。
3. **身宫与福德**：身宫落宫定后天重心；福德宫定精神层次（女命尤重）。
4. **四化定焦点**：生年化禄所在宫＝机缘财源；化忌所在宫＝一生纠结点、化忌冲对宫之事亦受损。
5. **分宫细论**（按用户所问）：婚姻看夫妻宫、财看财帛+田宅+福德、事业看官禄、健康看疾厄。宫位含义与"宫星体用生克"法查 `references/palaces.md`；财、官、病专断词表查 `references/fortune.md`。
6. **大限流年断应期**：用 `--horoscope` 输出的大限/流年四化，按"本命为因、大限为缘、流年为果"三层叠加论应期。方法详见 `references/fortune.md` 第一节。

### 第4步：输出规范

- **先呈现命盘要点**（命宫主星亮度、五行局、格局、生年四化落宫），让用户可核对，再展开解读。
- 引用星曜必附亮度与所在宫（如"武曲(得)化权坐财帛"），确保每个论断可溯源到脚本输出。
- 论断分层：性格才能 → 格局高度 → 各宫吉凶 → 运势应期 → 建议。有吉说吉、有凶说凶，凶处必给制化之道（书中原则：煞有制则为我所用）。
- 古法中性别、克应类断语（旺夫、克父等）转译为现代性格/关系能量表述。
- 结尾注明：紫微斗数为传统命理文化参考，非科学预测，重大决策应依理性判断。

## 常见陷阱

- 时辰用0-23钟点传给 `--hour`，脚本自动转时辰；23点是晚子时（当日日期+子时排法），勿手动改日期。
- 成格条件差一宫即不成格，勿强套格局；判格最后必查"禄忌有无"（逢禄呈吉、忌扰逞凶）。
- 单宫不论命：任何宫位的论断必须先看其三方四正会照。
- 各派四化（戊庚壬干）有异说，一律以脚本输出为准。
