# 十二宫与推断方法（源自《图解紫微斗数·命理卷》第三、六章）

## 十二宫含义

| 宫位 | 所主 | 论断要点 |
|---|---|---|
| 命宫 | 先天格局、性情才能、一生总纲 | 全盘枢纽，与身宫、福德宫合参 |
| 兄弟宫 | 兄弟姐妹、平辈助力、合伙人 | 亦看母亲（一说）、现金流位 |
| 夫妻宫 | 婚姻感情、配偶状况 | 与福德宫（对照三方）、红鸾天喜合参 |
| 子女宫 | 子女、晚辈、创造力、桃花性生活 | 亦看合伙下游、意外之灾（对田宅） |
| 财帛宫 | 财运、理财方式、金钱观 | 与福德宫（对宫）互为表里 |
| 疾厄宫 | 健康体质、灾病 | 与父母宫、命宫五行合参（详见 fortune.md） |
| 迁移宫 | 出外运、人际际遇、变动 | 命宫对宫，直冲命宫，在外发展吉凶 |
| 交友宫（奴仆） | 朋友部属、群众关系 | 看用人、追随者之助力或拖累 |
| 事业宫（官禄） | 事业性质、成就、适合行业 | 与命财官三方构成"三方"核心 |
| 田宅宫 | 不动产、家运、财库 | 一切财富最终归宿，库位 |
| 福德宫 | 精神享受、福分、寿元、价值观 | 女命尤重；主内心世界与晚年 |
| 父母宫 | 父母、长辈上司、文书相貌 | 亦名相貌宫，看遗传与庇荫 |

**身宫**：后天运势与努力方向，35岁后影响力渐强。身宫必落于命/夫妻/财帛/迁移/事业/福德六宫之一，落于何宫，人生重心即偏向该宫所主。

## 宫位关系（论断的空间结构）

- **三方四正**：本宫 + 对宫（四正）+ 三合两宫（三方）。如命宫在午，则三方四正为：午（本）、子（对宫迁移）、寅（事业）、戌（财帛）。**论任何一宫，必看其三方四正会照的所有星曜**，单看一宫必失准。
- **对照（冲）**：对宫星曜直接影响本宫，凶星冲照力量甚于同宫。
- **夹宫**：左右邻宫夹持。吉夹（如左辅右弼夹、化禄化科夹、财荫夹印）增福；凶夹（如羊陀夹忌、火铃夹命、刑忌夹印）为祸剧烈。
- **借星安宫**：本宫无主星时，借对宫主星论之，但力量打七折，且性质带"外来、不稳"之意。

## 论命总纲（第六章要诀）

1. **命与运分论**：命（本命盘）为先天之"体"，运（大限流年）为后天之"用"。命好运差如良马困途，命差运好亦有一时风光。
2. **命盘解读顺序**：
   a. 先看命宫主星及亮度 → 定人之根本性情才干；
   b. 次看三方四正会照吉凶 → 定格局高低（吉星多寡、煞星多寡、有无四化）；
   c. 再看身宫、福德宫 → 定后天走向与精神层次；
   d. 寻生年化忌所在 → 定一生纠结点；寻化禄所在 → 定机缘财源；
   e. 逐宫检视六亲、财官田等各宫；
   f. 最后配合大限流年推吉凶应期。
3. **男命女命**：男命重命宫、事业、财帛、迁移；女命传统重夫妻、子女、福德（现代论命男女渐同，但福德宫于女命仍具特殊参考价值）。
4. **宫与星的五行生克（体用论，本书特色）**：
   - 宫位地支有五行，星曜有五行。星与宫、星与星之间以生克制化论强弱。
   - 生克之妙在"中和"，过旺过衰皆非所欲。
   - 阳生阴、阴生阳（异性相生）＝有情之生，最为珍贵；同性相生＝无情，生涩苛刻。
   - 阳克阳、阴克阴（同性相克）＝无情之凶克；异性相克＝有情之克，克中有生，为适度刺激。
   - **体用判法**：一宫只有一颗主星→以主星为体、以宫为用；两主星同宫→吉+吉互为体用（取亮度高者为体更精）；吉+凶→吉星为体、凶星为用；凶+凶→以强庙者为体、衰陷者为用。以体用生克有情无情断该宫吉凶。
5. **煞星哲学**：煞星非全凶——庙旺之煞是激发力（擎羊庙旺为权威、火铃遇贪狼为横发）；吉星落陷亦难为福。观其"制化"：煞有制（吉星同宫压制、庙旺、化吉）则为我所用。
